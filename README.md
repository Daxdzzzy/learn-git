# Learn Git

Working through **[Pro Git, 2nd ed.](https://git-scm.com/book/en/v2)** chapter by chapter, a little every day — theory notes plus hands-on labs.

## How this repo works

- **Notes** — one file per book section (`chapters/NN-*/notes/`), written in my own words.
- **Labs** — short, reproducible exercises (`chapters/NN-*/labs/`). Each lab has a `setup.sh` that builds a practice repo in `/tmp/learn-git/`, so any lab can be redone from scratch.
- **Chapter review** — a closing quiz before moving to the next chapter.
- **[CHEATSHEET.md](CHEATSHEET.md)** — every command learned, one line each.

### Lab format

| Step | Purpose |
|---|---|
| Warm-up | Recall earlier material from memory (retrieval practice) |
| Concept | Minimum theory, ≤5 sentences |
| Tasks | Graded tasks, each with a **Check** to self-verify |
| Break it / Fix it | Cause a problem on purpose, then recover |
| Explain it | Teach the concept in plain words (Feynman technique) |
| Review | Mistakes made and what corrected them |
